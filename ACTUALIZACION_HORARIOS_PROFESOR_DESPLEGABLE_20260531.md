# Actualización: horarios desplegables para reserva de salón

Se ajustó el módulo **Reservar salón** del rol **Profesor** para que los campos de hora funcionen de forma clara mediante listas desplegables:

- **Hora de inicio:** muestra opciones desde 07:00 hasta 16:00.
- **Hora de término:** muestra opciones desde 08:00 hasta 17:00.
- Al seleccionar hora de inicio, la hora de término se actualiza para mostrar únicamente horarios posteriores hasta 17:00.
- Se conservan las validaciones de lunes a viernes y rango institucional de 07:00 a 17:00.
- El frontend compila correctamente después del ajuste.
