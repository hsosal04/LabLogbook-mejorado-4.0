Paquete del proyecto LabLogbook

Contenido principal:
- Carpeta LabLogbook/: código fuente del proyecto actualizado.
- Archivo README.md: guía general del proyecto.
- Archivo CAMBIOS_REALIZADOS.md: resumen de ajustes aplicados.
- Archivo GUIA_CONCORDANCIA_TESIS.md: relación entre el proyecto y la tesis.

Objetivo de esta versión:
Dejar el proyecto con una presentación más clara, coherente y defendible dentro del documento de tesis, especialmente en los apartados de arquitectura, módulos, reportes, uso por roles y resultados.

Nota:
Para una entrega académica formal se recomienda comprimir únicamente el código fuente y los archivos de configuración, evitando incluir dependencias instaladas localmente o entornos virtuales completos.

Versión alineada con el protocolo de tesis actualizado. Se respetan fondos institucionales BUAP/FCC y se ajustan textos visibles de la app a bitácoras, asistencias, actividades, percances, laboratorios, salones y solicitudes académicas.
